# 받았수당

일한 만큼, 제대로 받았수당?

시급제 청년 근로자가 근로계약서와 급여명세서를 바탕으로 계약 조건을 점검하고, 예상 급여를 실제 지급액과 비교할 수 있게 돕는 해커톤 프로젝트입니다.

현재는 프로젝트 뼈대 단계입니다. 작업 기준은 [AGENTS.md](AGENTS.md)에 있습니다.

## 폴더 구조

| 폴더 | 용도 |
| --- | --- |
| `app/` | 업로드, 추출값 확인, 결과 화면 |
| `llm/` | 문서 항목 추출, 특약 분류, 챗봇 및 대응 문구 |
| `engine/` | 급여 계산과 계약서 점검 규칙 |
| `rag/` | 공식 조문과 용어 자료 검색 |
| `schemas/` | 추출 결과와 엔진 결과의 데이터 형식 |
| `config/` | 연도별 기준값 |
| `data/` | 팀이 수집하는 공식 조문, 용어 사전, 상담 경로 |
| `tests/` | 단위 테스트와 가상 테스트 자료(`tests/fixtures/`) |
| `docs/` | 기획 문서와 참고 자료 |

## 개발 환경 파일

- `requirements.txt`에는 기능 구현에 필요한 Python 패키지를 추가합니다.
- 환경 변수가 필요한 시점에 `.env.example`을 참고해 로컬 `.env`를 설정합니다. 실제 API 키는 `.env`에 보관합니다.
