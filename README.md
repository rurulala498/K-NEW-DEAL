# 받았수당

일한 만큼, 제대로 받았수당?

시급제 청년 근로자가 근로계약서와 급여명세서를 바탕으로 계약 조건을 점검하고, 예상 급여를 실제 지급액과 비교할 수 있게 돕는 청년 지원 서비스입니다.

## 로컬 실행

저장소 최상위에서 실행합니다. Python 3.11 이상을 사용합니다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app/main.py --server.address 127.0.0.1
```

**동의하고 시작하기**를 누르고 **정상 지급 샘플 열기** 또는 **확인 필요 샘플 열기**를 선택합니다. 가상 원본과 추출값을 비교하고 **결과 보기**를 누르면 규칙 엔진이 급여 영수증을 계산합니다. 챗봇과 사업주에게 보낼 문구는 시연용입니다.

텍스트 PDF, DOCX, TXT를 올리고 **서류 읽기**를 누르면 AI가 원문 근거와 함께 항목을 추출합니다. 업로드한 서류는 앱의 세션 메모리에서 처리합니다. AI로 읽을 때는 추출할 텍스트를 OpenAI API로 보냅니다. 이미지나 스캔 서류에서는 텍스트가 들어 있는 파일을 사용합니다.

저장소 최상위의 `.env`에 `OPENAI_API_KEY`와 Structured Outputs를 지원하는 `OPENAI_MODEL`을 설정합니다. 기존 샘플 카드에서는 저장된 결과를 사용하며, **샘플 서류를 AI로 직접 읽어 보기**에서만 가상 서류를 API로 보냅니다. 성공한 가상 서류 결과만 메모리에 캐시합니다.

가상 서류 3종의 항목별 일치율과 호출당 토큰을 직접 측정할 수 있습니다.

```powershell
python scripts/eval_extraction.py
```

실제 API를 사용하는 pytest는 기본적으로 건너뜁니다. 실행하려면 `RUN_LIVE=1`을 설정합니다.

```powershell
python -m pytest -q
```

## 폴더 구조

| 폴더 | 용도 |
| --- | --- |
| `app/` | 업로드, 추출값 확인, 결과 화면 |
| `llm/` | 문서 항목 추출, 특약 분류, 챗봇 및 대응 문구 |
| `engine/` | 급여 계산과 계약서 점검 규칙 |
| `rag/` | 공식 조문과 용어 자료 검색 |
| `schemas/` | 추출 결과와 엔진 결과의 데이터 형식 |
| `config/` | 연도별 기준값 |
| `data/` | 팀이 수집하는 공식 조문, 용어 사전, 상담 경로 |
| `tests/` | 단위 테스트와 가상 테스트 자료(`tests/fixtures/`) |
| `docs/` | 기획 문서와 참고 자료 |

작업 기준은 [AGENTS.md](AGENTS.md)에 있습니다.
